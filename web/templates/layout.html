О проекте

Учёт личных трат — учебный проект по веб-разработке на Go.

Технологический стек:

  • Язык: Go (стандартная библиотека)
  • HTTP-сервер: net/http
  • Шаблоны: html/template
  • Хранилище: память (этап 2), далее SQLite

Маршруты:

  • / — главная страница
  • /about — описание проекта
  • /ping — health-check (только GET, иначе 405)
  • /expenses — список трат
  • /expenses/new — форма добавления
